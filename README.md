# BLOB BRAWL

لعبة قتال جماعية أونلاين بشخصيات جيلاتينية وفيزياء "خرقة" (مستوحاة من Gang Beasts). تعمل في المتصفح على الكمبيوتر والجوال.

## التشغيل
1. ثبّت [Node.js](https://nodejs.org) (مرة واحدة).
2. شغّل `start.bat` — يفتح اللعبة على `http://localhost:3000`.
3. أصحابك على نفس الشبكة يفتحون رابط `Network` الذي يظهر في النافذة.
4. من خارج البيت: `start-online.bat` (يحتاج `winget install Cloudflare.cloudflared` مرة واحدة)، أو انشر المجلد على استضافة Node (ملف `render.yaml` جاهز لـ Render).

## كيف تفوز
1. اضرب راس الخصم حتى يُغمى عليه (أول إغماء قصير، وكل مرة يطول).
2. امسكه بالإيدين وارفعه فوق راسك.
3. امشِ للحافة وافلته لترميه. آخر واحد واقف يفوز بالجولة.

## التحكم
| | كمبيوتر | جوال | يد تحكم |
|---|---|---|---|
| حركة | WASD | العصا (يسار الشاشة) | العصا اليسرى |
| قفز / جري (ضغط مطوّل) / تسلّق | Space | ⤒ | A |
| اليد اليسرى: ضغطة = لكمة، مطوّل = مسك | J أو كليك يسار | 👊 للّكم، ✋ للمسك | LB |
| اليد اليمنى | K أو كليك يمين | نفس الأزرار | RB |
| رفع | L أو Shift | 🙌 | Y |
| ركلة (بالهواء = ركلة طائرة) | F | 🦵 | X |
| نطحة | H أو E | 💥 | B |

على الجوال زرّا المسك والرفع "يثبتان" بضغطة ويُفلتان بضغطة ثانية؛ وأنت رافع، إفلات المسك يرمي.

## المحتوى
- 10 مراحل: السطح، الحلبة، المترو، المطحنة، المحرقة، الشاحنات، المنطاد، العوارض، الحاويات، المصاعد.
- 33 شخصية جاهزة + تخصيص حر: لون الجسم، 33 زيّاً، لون الزي، 27 غطاء راس، 10 إكسسوارات وجه.
- نمطان: الكل ضد الكل، وفرق. بوتات اختيارية.

## للمطوّرين
- `server.js` الغرف والشبكة · `src/sim.js` الفيزياء والقواعد · `src/bots.js` البوتات
- `public/shared/` بيانات مشتركة (الهيكل، المراحل، المظاهر) · `public/js/` العميل (three.js)
- `npm test` اختبارات الفيزياء بدون واجهة · `node test/stats.mjs 4` إحصائية مدة الجولات مع البوتات
