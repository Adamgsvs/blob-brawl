# BLOB BRAWL — لعبة معارك 3D أونلاين (مثل Gang Beasts)

## التشغيل
1. ثبّت Node.js (https://nodejs.org) مرة وحدة.
2. دبل كليك على `start.bat` ← بيفتح اللعبة على `http://localhost:3000`.
3. **صحابك على نفس الواي فاي:** يفتحوا رابط `Network` اللي بيظهر بالنافذة (مثلاً `http://192.168.1.5:3000`) من الجوال أو الكمبيوتر.
4. **صحابك من بره البيت:** شغّل `start-online.bat` (يحتاج `winget install Cloudflare.cloudflared` مرة وحدة) وابعتلهم رابط `trycloudflare.com`.
   أو ارفع المجلد على أي استضافة Node (Render / Railway) — أمر التشغيل `npm start`.

## كيف تلعب مع صحابك
- أنت: **إنشاء غرفة** ← بيطلع رمز من 4 حروف (أو زر **نسخ الرابط**).
- صحابك: يكتبوا الرمز في **دخول** أو يفتحوا الرابط مباشرة.
- بالوبي: اختار الشخصية (لون/قبعة/وجه)، الخريطة، النمط (فردي/فرق)، عدد الجولات، وضيف بوتات.

## التحكم
| | كمبيوتر | جوال |
|---|---|---|
| حركة | WASD / الأسهم | عصا الحركة (يسار) |
| نط / تسلّق | Space | زر ⬆ |
| ضرب | J / Z / كليك يسار | 👊 |
| مسك (اضغط مطوّلاً) | K / Shift / كليك يمين | ✋ |
| رمي لاعب | وإنت ماسكه اضغط ضرب | نفس الشي |
| إيموجي | 1–8 أو E | 😜 |
يد التحكم (Gamepad) مدعومة.

## ملاحظات للأجهزة الضعيفة
الفيزياء كلها على السيرفر، فالجهاز الضعيف بس يرسم. الجودة تنخفض تلقائياً لو الإطارات قلّت، ويمكنك اختيارها يدوياً من ⚙️ الإعدادات.

## اختبار
`npm test` يشغّل اختبار الفيزياء بدون واجهة.
